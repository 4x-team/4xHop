## English Description

**4xHop** is an advanced, client-side only Bunnyhop (Bhop), Auto-Bhop, and Air-Strafe modification built for Minecraft 1.20.1 using the official Minecraft Forge MDK.

### Key Features:
- **Client-Side Only**: Safe for use on multiplayer servers without crashing or requiring server-side components.
- **Auto-Bhop**: Automatic jump timing on ground contact while holding the Jump key, with automatic sprint synchronization.
- **Manual Bhop**: Rewards precise jump timing (within a 1–2 tick window after landing) with speed bonuses. Resets if the player stays on the ground for more than 2 ticks.
- **Air-Strafe Mode**: Vector-based physics that redirect horizontal movement according to camera yaw and input synchronization (A/D strafe keys), with realistic acceleration dampening when holding Forward (W).
- **In-Game Configuration**:
  - Interactive GUI screen with mode switching, automatically presented on first world join.
  - Client-side command: `/4xhop` (opens settings GUI) and `/4xhop bhop` (cycles between Default and Strafe modes).
  - Status display in the Actionbar using clean, non-obtrusive Unicode typography (`minecraft:uniform`).
  - Hotkeys: `[` (+10% speed), `]` (-10% speed), `I` (Toggle Auto-Bhop).
- **Open Source**: Licensed under the MIT License and developed by FoxTeam.

## Описание на русском

**4xHop** — продвинутый клиентский мод для Minecraft 1.20.1 (Minecraft Forge), добавляющий систему Bunnyhop (Bhop), Auto-Bhop и настраиваемый Air-Strafe.

### Основные возможности:
- **Исключительно клиентская часть (Client-Side Only)**: Работает на выделенных серверах без сбоев и не требует установки серверной части.
- **Auto-Bhop**: Автоматический прыжок ровно в тик соприкосновения с землей при зажатом Пробеле с автоматической синхронизацией спринта.
- **Manual Bhop (Ручной бхоп)**: Система идеальных таймингов — прыжок в окне 1–2 тиков после приземления добавляет бонус к горизонтальной скорости. При нахождении на земле дольше 2 тиков бонус сбрасывается.
- **Режим Strafe Bhop (Air-Strafe)**: Векторная физика перенаправления импульса в воздухе по направлению взгляда при синхронизации клавиш A/D с поворотом камеры, со снижением ускорения при зажатии W.
- **Удобное управление и интерфейс**:
  - Графический интерфейс (GUI) для выбора режима, автоматически открывающийся при самом первом входе в мир.
  - Клиентская команда: `/4xhop` (открытие GUI) и `/4xhop bhop` (быстрое переключение режимов).
  - Информативный и аккуратный Actionbar на чистом Unicode-шрифте (`minecraft:uniform`).
  - Горячие клавиши: `[` (+10% к скорости), `]` (-10% к скорости), `I` (переключение Auto-Bhop).
- **Открытый исходный код**: Проект с открытым исходным кодом под лицензией MIT, разрабатываемый FoxTeam.
